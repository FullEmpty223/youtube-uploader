Privacy Policy

Last updated: November 19, 2026

tubectl ("the tool") is a single-user command-line tool operated by SEONGGYU KIM for managing the operator's own YouTube channels.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy also applies.

Information the tool accesses

  • An OAuth access token and refresh token for each YouTube channel the operator authorizes, granted through Google's consent screen.
  • The authorized channel's ID, name, and handle, used to label the channel and to prevent actions on the wrong channel.
  • Metadata and statistics of the operator's own videos (video ID, title, description, tags, privacy and schedule status, view count) returned by the API.
  • When the planned features are added: comments on the operator's own videos, and analytics reports for the operator's own channels.

The tool does not access data of channels the operator does not own or manage, and does not collect personal information from viewers.

How the information is used

Tokens are used only to perform the actions the operator runs: uploading, editing, scheduling, listing, and deleting the operator's own videos, and (when added) managing playlists, comments, and viewing reports for the operator's own channels. Data returned by the API is shown to the operator in the terminal.

Storage and sharing

  • Tokens and channel labels are stored only in local files on the operator's own computer, readable only by the operator's user account. There is no server or database.
  • Video metadata, statistics, comments, and reports are displayed and not stored by the tool, except a video's ID and URL that the operator may record in local project files.
  • No information is shared with, sold to, or disclosed to any third party.
  • The tool uses no cookies, analytics, or tracking.

Retention and deletion

Local data is kept only as long as the tool is in use. Running tubectl logout revokes a channel's token and deletes it; removing the tool's configuration folder deletes all local data. Any stored API data is refreshed or deleted within 30 days.

Revoking access

Access can be revoked at any time through the Google security settings page: https://security.google.com/settings/security/permissions. After revocation the tool can no longer access the account.
