Blue Avocado Uploader

Blue Avocado Uploader is a private, single-user command-line tool. Its only user is the operator, SEONGGYU KIM, who uses it to upload self-produced videos to the operator's own YouTube channel.

What it does

  • Uploads a finished video file from the operator's computer to the operator's own channel (videos.insert).
  • Sets the title, description, tags, and privacy status, and uploads the custom thumbnail (thumbnails.set).

What it does not do

  • It is not offered to other people. It has no sign-up, no web service, and no other users.
  • It does not read, collect, or analyze other channels' data, comments, or viewers.
  • It does not download YouTube content and does not use the API for search or scraping.

How it works

The operator renders a video on a Mac, then runs the tool from the terminal. On first use, Google's OAuth consent screen asks the operator to authorize the operator's own YouTube account. The tool keeps the resulting token in a local file on that Mac and uses it only to upload and update the operator's own videos.
